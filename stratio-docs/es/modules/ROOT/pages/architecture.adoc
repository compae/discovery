= Arquitectura

_Stratio Discovery_ es una herramienta fácil de usar que permite conectarse con múltiples bases de datos para hacer analítica, cuadros de mando e informes:

image::arquitectura.png[]

_Stratio Discovery_ encapsula todas las funcionalidades del producto *Metabase* (aquí https://www.metabase.com/docs/v0.42/[más información]), un producto de analítica que permite conectarse a diversos servicios de datos a través de sus conectores y, de forma modular, incluir nuevos conectores.

En el caso de _Stratio Discovery_, se incluyen dos nuevos conectores para utilizar con cualquier repositorio de datos accesible a través de _Stratio PostgreSQL_ y _Stratio Virtualizer_, además de poder conectarse con otros servicios externos siempre que sean soportados por *Metabase*:

image::arquitectura2.png[]

Su arquitectura, por tanto, está basada en la propia arquitectura de *Metabase*, pero además aporta dos características fundamentales:

. Acceso securizado de usuarios, homogeneizado en la plataforma (a través de un proxy HTTP NGINX).
. Acceso a todos los datos internos a la plataforma: _Stratio Virtualizer_ (vía _Crossdata driver_) y _Stratio PostgreSQL_ (vía _JDBC driver_).

image::arquitectura3.png[]

Consulta la https://www.metabase.com/learn/administration/metabase-at-scale[documentación de la arquitectura de Metabase] para más información.

De esta forma, la potencia de _Stratio Discovery_ permite acceder de forma uniforme, homogénea y transparente a datos internos y externos a la plataforma, así como relacionarlos y hacer preguntas sobre ellos… en resumen, hacer analítica e informes de análisis.
