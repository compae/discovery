= Novedades

Estos son los últimos cambios realizados en _Stratio Discovery_ versión *0.50.21-0.1.x* (lanzado originalmente en octubre de 2024 y siendo el último _patch_ 0.50.21-0.1.3, lanzado en mayo de 2025):

* Actualización de Metabase: ahora se utiliza la versión 0.50.21, aunque ciertas funcionalidades como acciones, modelos creados desde CSV, _timelines_ y alertas no son compatibles con la exportación/importación de colecciones de _discovery-cicd_.
 Actualización del _driver_ JDBC de _Stratio Virtualizer_ a la versión 2.31.0.
* Se ha añadido una opción de despliegue en _Stratio Command Center_: "Extra JARs to add to metabase plugins folder", para especificar una lista de URL con ficheros JAR que se añadan a la carpeta de _plugins_ de Metabase. Esto permite añadir nuevos _drivers_ o dependencias necesarias, como el JDBC de Oracle requerido por el _driver_ de Metabase de Oracle (variable de entorno: `EXTRA_JARS`).
* Se ha añadido una opción de despliegue en _Stratio Command Center_, "Hex-encode user-provided parameters in SQL queries", para configurar el mecanismo de prevención de inyección SQL al interpolar parámetros en consultas SQL de _Stratio Virtualizer_. La codificación hexadecimal es más segura, pero puede causar problemas cuando la consulta se resuelve de forma nativa y el almacén de datos no sabe descodificar los parámetros (variable de entorno: `VIRTUALIZER_DRIVER_HEX_ENCODE_SQL_PARAMS`).
* Soporte para usar preguntas como valores en filtros de otras preguntas al exportar e importar colecciones en _discovery-cicd_.
* Se ha añadido una opción de despliegue en _Stratio Command Center_ para evitar el bloqueo de conexiones JDBC con servidores _Stratio Virtualizer_ anteriores a la versión 0.11.0. La nueva configuración "Skip Metabase's Statement final cancellation in Virtualizer driver" permite deshabilitar la cancelación automática de _statements_ JDBC que causaba este problema (variable de entorno: `VIRTUALIZER_DRIVER_SKIP_STMT_CANCELLATION`).
* Se ha solucionado un problema en el _driver_ de _Stratio Virtualizer_ que impedía la sincronización de esquemas y nombres de tablas que contuviesen guiones (actualización del JDBC de _Stratio Virtualizer_ a la versión 2.31.0).
* Se ha solucionado un problema en el _driver_ de _Stratio Virtualizer_ por el que no se utilizaba el dialecto SQL correcto para el formateo de consultas SQL.

== _Breaking changes_

* La integración con el SSO de _Stratio Gosec_ ha cambiado. Ahora, el flujo de Oauth2 se delega en el _oauth2proxy_ de _Stratio KEOS_ y ya no se usa la _cookie_ "discovery-oauth-cookie". En su lugar, se establece la _stratio-cookie_, que contiene un _token_ JWT con la información del usuario muy similar a la incluida en la _cookie_ anterior, con la ventaja de que este nuevo _token_ es reconocido por el resto de las aplicaciones de Stratio. Además, el acceso a la API de Metabase ya no requiere que se incluya esta _cookie_ y solo hace falta la _cookie_ "metabase.SESSION". Las integraciones con la API de _discovery-cicd_ que simulaban un _login_ para recuperar la _cookie_ "discovery-oauth-cookie", para luego obtener una _cookie_ "metabase.SESSION", deberán ajustarse para usar la nueva _stratio-cookie_ en su lugar.
