= Novedades

Estos son los últimos cambios realizados en _Stratio Discovery_ versión *0.43.4-0.2.0* (lanzado en septiembre de 2023):

* Importación y exportación de _snippets_ de código SQL en _discovery-cicd_.
* Gestión correcta de _questions_ que tengan enlaces a otras _questions_ o _dashboards_ en _discovery-cicd_.
* Soporte para _placements_ y _priority classes_ en el despliegue de _Stratio Discovery_.

TIP: Consulta las xref:ROOT:what-is-new/release-notes.adoc[notas de _release_] anteriores para obtener más información.
