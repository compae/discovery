= Guía de usuario

Esta guía permite saber más sobre _Stratio Discovery_ y cómo realizar consultas sobre el almacén de datos. Va dirigida a un público que no necesita tener conocimientos técnicos, aunque es una cualidad deseable. Su principal objetivo es *crear preguntas y aprender de los datos de la empresa*.

_Stratio Discovery_ funciona con Metabase, por lo que puedes encontrar más información en su https://www.metabase.com/docs/v0.42/users-guide/start.html[guía de usuario]^[English]^.

== Prerrequisitos

Hay algunos requisitos que se deben cumplir antes de comenzar a usar _Stratio Discovery_, sin embargo, los siguientes son los más relevantes:

* Debe haber una instancia de _Stratio Discovery_ ejecutándose y configurada correctamente en el _cluster_.
* El usuario debe conocer la URL donde se implementa el servicio.

== Conoce _Stratio Discovery_

_Stratio Discovery_ es una herramienta sencilla de inteligencia de negocio (BI). Permite hacer preguntas sobre los datos y muestra las respuestas en formatos que tienen sentido, ya sea un gráfico de barras o una tabla detallada.

Las preguntas se pueden guardar para más adelante, lo que permite volver a ellas y/o agruparlas en _dashboards_ con buena apariencia. También es posible compartir preguntas y paneles con el resto del equipo usando *colecciones*.

Para entender completamente cómo usar _Stratio Discovery_ es muy útil tener conocimientos de alto nivel de las bases de datos, por lo que a continuación se muestran https://www.metabase.com/learn/databases/database-basics[los conceptos básicos de las bases de datos]^[English]^ que conviene tener en cuenta.

=== ¿Qué puedo hacer?

_Stratio Discovery_ permite realizar varias operaciones como:

* Crear preguntas.
* Obtener respuestas en forma de gráficos.
* Compartir preguntas.
* Crear _dashboards_.
* Realizar colecciones colaborativas.
* Perfilar los datos con _X-ray_.
