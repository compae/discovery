= Problemas conocidos

== _Troubleshooting_ de Metabase

En caso de experimentar algún problema al usar _Stratio Discovery_, consulta la https://www.metabase.com/docs/v0.43/troubleshooting-guide/index.html[guía de _troubleshooting_ de Metabase]^[English]^.

== No puedo especificar correctamente el fichero (_key_) que contiene la clave privada del certificado para crear una conexión con una base de datos de PostgreSQL mediante SSL.

Este es un _bug_ de Metabase que se ha resuelto en la versión 0.42.3 y posteriores. Si tienes una versión anterior y quieres establecer una conexión SSL con PostgresSQL, ten en cuenta que `File Path` de `SSL Client Key (PKCS-8/DER o PKCS-12)` podría no parsearse correctamente y tendrías que indicar la configuración asociada (`sslkey`) en el campo `Additional JDBC connection string options`. Esta incidencia no aplica si utilizas la base de datos _Stratio PostgresSQL_.

== Cuando entro a la página principal, las exploraciones _x-ray_ no se cargan automáticamente

Este es un problema menor causado por la capa de autenticación que añade _Stratio Discovery_ a Metabase. Para representar el contenido de la página principal, se deben recuperar algunas configuraciones de usuario sobre si se deben mostrar o no sugerencias _x-ray_ (por ejemplo, hay muchas formas de https://www.metabase.com/docs/latest/users-guide/14-x-rays.html#disabling-x-rays[desactivar la funcionalidad de _x-ray_]^[English]^. Lamentablemente, esta llamada a _get-properties_ no está autenticada y, debido a una condición de carrera, puede ejecutarse antes que las llamadas que establezcan una cookie válida de `metabase.SESSION` tras el _login_.

Dado que se devolverán estas propiedades si y solo si el usuario es de confianza después de haber comprobado que se ha completado la autenticación, si la segunda llamada se ejecuta antes que la primera, todo funcionará correctamente, pero si es al contrario, se devolverá un valor `undefined` o vacío que no se representará en la página principal.

La solución para este problema es refrescar la página principal una vez que se ha realizado el _login_. Dado que ya se habrá escrito la _cookie_ de autenticación, a partir de ahí ya no importará el orden de ejecución.

== La importación de colecciones devuelve un _timeout_

* *Causa*: la importación de colecciones grandes a veces puede devolver un error de tiempo de espera aunque la operación se haya procesado.
* *Solución*: aunque el servicio de importación devuelva este error, comprueba si la operación se ha realizado correctamente.

== Problemas de deserialización de caché

Por una vulnerabilidad de seguridad descubierta en una de las dependencias de Metabase, el artefacto de Metabase distribuido con _Stratio Discovery_ se compila utilizando una versión actualizada de esta dependencia que ya no contiene la vulnerabilidad.

Esto puede causar problemas en algunos casos cuando se activa la caché de Metabase, si una de las columnas de los resultados cacheados tiene un tipo cuya seguridad de deserialización no puede garantizarse por Metabase (esto ocurre, por ejemplo, con los tipos _interval_ y _json_ de PostgreSQL).

No se devolverán errores, pero los resultados obtenidos de la caché para esta columna en particular no se podrán utilizar (contendrán un mapa con los _bytes_ no deserializados "en cuarentena"). Ten en cuenta que cualquier usuario puede siempre activar una ejecución manual de la consulta (sin usar los datos cacheados) para obtener los resultados correctos.
