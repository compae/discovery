= Notas de _release_

Estos son los aspectos más destacados de _Stratio Discovery_ en los últimos lanzamientos:

== 0.56.4-0.1.1 (5 de diciembre de 2025)

* Actualización del _driver_ JDBC de _Stratio Virtualizer_ a la versión 3.0.1.

== 0.56.4-0.1.0 (4 de noviembre de 2025)

* Actualización de Metabase: ahora se utiliza la versión 0.56.4. Ciertas funcionalidades introducidas en Metabase 0.51, como acciones, modelos creados desde CSV, _timelines_ y alertas, siguen sin ser compatibles con la exportación/importación de colecciones de _discovery-cicd_.
* Actualización del _driver_ JDBC de _Stratio Virtualizer_ a la versión 3.0.0.
* Se ha añadido una opción de despliegue en _Stratio Command Center_: "Use virtualizer jdbc from Extra JARs" (variable de entorno `VIRTUALIZER_JDBC_FROM_EXTRA_JARS`) para no usar el _driver_ JDBC de _Stratio Virtualizer_ incluido en la imagen, sino obtenerlo de los "Extra JARs to add to metabase plugins folder" (variable de entorno `EXTRA_JARS`).
* *_Breaking change_*: se ha eliminado la opción de despliegue en _Stratio Command Center_ "Skip Metabase's Statement final cancellation in Virtualizer driver" (variable de entorno: `VIRTUALIZER_DRIVER_SKIP_STMT_CANCELLATION`). Esta opción evitaba el bloqueo de conexiones JDBC con servidores _Stratio Virtualizer_ anteriores a la versión 0.11.0; por tanto, ahora es necesario conectarse a servidores con versión 0.11.0 o superior.

== 0.50.21-0.1.3 (12 de mayo de 2025)

* Se ha añadido una opción de despliegue en _Stratio Command Center_: "Extra JARs to add to metabase plugins folder", para especificar una lista de URL con ficheros JAR que se añadan a la carpeta de _plugins_ de Metabase. Esto permite añadir nuevos _drivers_ o dependencias necesarias, como el JDBC de Oracle requerido por el _driver_ de Metabase de Oracle (variable de entorno: `EXTRA_JARS`).
* Se ha añadido una opción de despliegue en _Stratio Command Center_, "Hex-encode user-provided parameters in SQL queries", para configurar el mecanismo de prevención de inyección SQL al interpolar parámetros en consultas SQL de _Stratio Virtualizer_. La codificación hexadecimal es más segura, pero puede causar problemas cuando la consulta se resuelve de forma nativa y el almacén de datos no sabe descodificar los parámetros (variable de entorno: `VIRTUALIZER_DRIVER_HEX_ENCODE_SQL_PARAMS`).
* Soporte para usar preguntas como valores en filtros de otras preguntas al exportar e importar colecciones en _discovery-cicd_.
* Se ha solucionado un problema en el _driver_ de _Stratio Virtualizer_ que impedía la sincronización de esquemas y nombres de tablas que contuviesen guiones (actualización del JDBC de _Stratio Virtualizer_ a la versión 2.31.0).
* Se ha solucionado un problema en el _driver_ de _Stratio Virtualizer_ por el que no se utilizaba el dialecto SQL correcto para el formateo de consultas SQL.

== 0.50.21-0.1.2 (13 de noviembre de 2024)

* Se ha bajado la versión del JDBC de _Stratio Virtualizer_ a la 2.27.0 para evitar un problema presente en versiones superiores donde se daba un desbordamiento de memoria.

== 0.51.21-0.1.1 (8 de noviembre de 2024)

* Se ha añadido una opción de despliegue en _Stratio Command Center_ para evitar el bloqueo de conexiones JDBC con servidores _Stratio Virtualizer_ anteriores a la versión 0.11.0. La nueva configuración "Skip Metabase's Statement final cancellation in Virtualizer driver" permite deshabilitar la cancelación automática de _statements_ JDBC que causaba este problema (variable de entorno: `VIRTUALIZER_DRIVER_SKIP_STMT_CANCELLATION`).

== 0.51.21-0.1.0 (21 de octubre de 2024)

* Actualización de Metabase: ahora se utiliza la versión 0.50.21, aunque ciertas funcionalidades como acciones, modelos creados desde CSV, _timelines_ y alertas no son compatibles con la exportación/importación de colecciones de _discovery-cicd_.
* *_Breaking change_*: la integración con el SSO de _Stratio Gosec_ ha cambiado. Ahora, el flujo de Oauth2 se delega en el _oauth2proxy_ de _Stratio KEOS_ y ya no se usa la _cookie_ "discovery-oauth-cookie". En su lugar, se establece la _stratio-cookie_, que contiene un _token_ JWT con la información del usuario muy similar a la incluida en la _cookie_ anterior, con la ventaja de que este nuevo _token_ es reconocido por el resto de las aplicaciones de Stratio. Además, el acceso a la API de Metabase ya no requiere que se incluya esta _cookie_ y solo hace falta la _cookie_ "metabase.SESSION". Las integraciones con la API de _discovery-cicd_ que simulaban un _login_ para recuperar la _cookie_ "discovery-oauth-cookie", para luego obtener una _cookie_ "metabase.SESSION", deberán ajustarse para usar la nueva _stratio-cookie_ en su lugar.

== 0.43.4-0.3.0 (9 de febrero de 2024)

* Se ha corregido un problema donde el asunto de los correos de suscripción a _dashboards_ mostraban un UUID en lugar del nombre del _dashboard_.

== 0.43.4-0.2.0 (18 de septiembre de 2023)

* Importación y exportación de _snippets_ de código SQL en _discovery-cicd_.
* Gestión correcta de _questions_ que tengan enlaces a otras _questions_ o _dashboards_ en _discovery-cicd_.
* Soporte para _placements_ y _priority classes_ en el despliegue de _Stratio Discovery_.
* Uso de porcentajes para configurar la memoria de las máquinas virtuales de Java asociadas a Metabase y a _discovery-cicd_.
* Solución: mayor facilidad para configurar los _timeouts_ de _discovery-cicd_ para evitar errores comunes.
* Solución de vulnerabilidades: actualización del agente Java de Prometheus a 0.19.0 (vulnerabilidad del paquete SnakeYAML GHSA-mjmj-j48q-9wg2).
* Solución de vulnerabilidades: ya no se muestran las _cookies_ de sesión en los _logs_ de nivel `DEBUG` del servidor Jetty de Metabase.

== 0.43.4-0.1.4 (25 de abril de 2023)

* Se tiene en cuenta que las tarjetas pueden utilizar otras tarjetas como datos de entrada en _discovery-cicd_.

== 0.43.4-0.1.3 (21 de febrero de 2023)

* Solución: actualización del JDBC de Crossdata a la versión 2.24.0-7394c02 (para solventar la sincronización de tablas Delta)
