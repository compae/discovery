= Variables de entorno

Aquí puedes consultar todas las posibles propiedades de _Stratio Discovery_ para desplegar una instancia:

* *Propiedad*: nombre del campo.
* *Descripción*: descripción del valor y su uso.
* *Posible/por defecto*: valores posibles y valores predeterminados.
* *Obligatorio*: _true_ o _false_.
* *Tipo*: tipo de valor.

|===
| Propiedad | Descripción | Posible/por defecto | Obligatorio | Tipo

| cpus
| Cuotas de CPU para asignar a cada instancia de _Stratio Discovery_.
|
|
|

| instances
| Número de instancias de _Stratio Discovery_ para ejecutar.
|
|
|

| id
| El nombre de la instancia (predeterminado = /discovery).
|
|
|

| mem
| Memoria (MB) para asignar a cada instancia de _Bootstrap_.
| 2048
| Si
| Number

| force_pull_image
| Fuerza la descarga de la imagen de Docker cada vez que se crea una instancia.
| _true_
| Si
| Boolean
|===

*Seguridad*

|===
| Propiedad | Descripción | Posible/por defecto | Obligatorio | Tipo | Obsoleto

| String

| Si

| AAAA-BBBB-CCCC-DDDD

| MB_USER_HEADER

| No
| String
|

| MB_GROUP_HEADER
| Cacebcera HTTP con un _array_ de grupos para la autenticación automática.
| vnd.bbva.group-id
| No
| String

| MB_ADMIN_GROUP_HEADER
| Array de grupos que se configurarán con privilegios de administrador.

| discovery
| Si
| String
|

| AUTHENTICATOR

| Si
| String

| USE_GOSEC_SSO_AUTH
| Habilita la autenticación _Stratio GoSec_ SSO. Ten en cuenta que *establecer esta variable a `true` deshabilitará la autenticación mediante cabeceras*. Dirígete a la sección de 'logging' para obtener más información.
| _True_
| Si
| Boolean
| Obsoleta desde 0.38.1-0.2.

| ipAddress.networkName
| Nombre de la red de Calico. Utilízalo solo si la segmentación de red está habilitada.
| stratio

| String

|===

| por ejemplo `+https://public01.labs.stratio.com/discovery+`
| Si
| String
|

| MB_DB_DBNAME

| discovery

| String

| postgres

| String

| String

| MB_DB_SSL

| _false_
| Si
| Boolean

| Obsoleta desde 0.38.1-0.2.
