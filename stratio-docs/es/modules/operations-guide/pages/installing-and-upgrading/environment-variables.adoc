= Variables de entorno

Aquí puedes consultar todas las posibles propiedades de _Stratio Discovery_ para desplegar una instancia:

* *Propiedad*: nombre del campo.
* *Descripción*: descripción del valor y de su uso.
* *Posible/por defecto*: valores posibles y valores predeterminados.
* *Obligatorio*: Sí o No.
* *Tipo*: tipo de valor.

|===
| Propiedad | Descripción | Posible/por defecto | Obligatorio | Tipo

| SERVICE_ID
| El nombre de la instancia (predeterminado = /discovery).
| discovery
| Sí
| String

| KUBERNETES_NAMESPACE
| El nombre del _namespace_ en el que se encuentra la instancia.
| s000001-apps
| Sí
| String

| DEPLOYMENT_ENVIRONMENT
| Entorno de despliegue.
| keos
| No
| String

| TENANT
| _Tenant_ donde está desplegada la instancia.
| `${tenantId}`
| No
| String

| CPU_RESOURCE_TYPE
| Tipo de recurso de CPU a utilizar en cuanto al tipo de asignación en Kubernetes: +
- _Guaranteed_: recurso garantizado (solicitud = límite). +
- _Hard_: límite establecido, pero la solicitud puede ser menor. +
- _Soft_: sin límite, solo se establece la solicitud.
| _Guaranteed_
| Sí
| String

| CPUs
| Número de CPU solicitados por cada instancia de _Stratio Discovery_.
| 2
| Sí
| Number

| CPU_LIMIT
| En caso de que `CPU_RESOURCE_TYPE` sea _Hard_, este valor establece el límite de CPU para cada instancia de _Stratio Discovery_.
|
|
| Number

| INSTANCES
| Número de instancias de _Stratio Discovery_ a ejecutar.
| 1
| Sí
| Number

| MEM_RESOURCE_TYPE
| Tipo de memoria a utilizar en cuanto a tipo de asignación en Kubernetes: +
- _Guaranteed_: recurso garantizado (solicitud = límite). +
- _Hard_: límite establecido, pero la solicitud puede ser menor. +
- _Soft_: sin límite, solo se establece la solicitud.
| _Guaranteed_
| Sí
| String

| MEM
| Memoria (MB) asignada a cada instancia de _Stratio Discovery_.
| 4096
| Sí
| Number

| MEMORY_LIMIT
| En caso de que `MEM_RESOURCE_TYPE` sea _Hard_, este valor establece el límite de memoria para cada instancia de _Stratio Discovery_.
|
|
| Number

| JAVA_INITIAL_RAM_PERCENTAGE
| Porcentaje de memoria inicial de Java en relación con la memoria total asignada a la instancia.
| `-XX:InitialRAMPercentage=30.0`
| No
| String

| JAVA_MAX_RAM_PERCENTAGE
| Porcentaje de la memoria máxima de Java respecto de la memoria total asignada a la instancia.
| `-XX:MaxRAMPercentage=70.0`
| No
| String

| force_pull_image
| Fuerza la descarga de la imagen de Docker cada vez que se crea una instancia.
| _true_
| Sí
| Boolean
|===

*Seguridad*

|===
| Propiedad | Descripción | Posible/por defecto | Obligatorio | Tipo

| VAULT_ENABLE
| Habilita la integración con Vault para recuperar secretos.
| true
| No
| Boolean

| VAULT_HOST
| _Host_ de conexión de Vault.
| vault.keos-core
| No
| String

| VAULT_PORT
| Puerto de conexión de Vault.
| 8200
| Sí
| Number

| VAULT_ROLE
| Rol utilizado para recuperar un _token_ de Vault mediante una política predefinida. NOTA: solo se usa con la autenticación dinámica habilitada.
| `${Application.domain}-${Application.name}`
| No
| String

| USE_DYNAMIC_AUTHENTICATION
| Habilita la autenticación dinámica. En desuso desde la versión 0.56.4-0.2.x.
| true
| No
| String

| MB_USER_HEADER
| Cabecera HTTP con el nombre de usuario utilizado para la autenticación automática.
| vnd.bbva.user-id
| No
| String

| MB_GROUP_HEADER
| Cabecera HTTP con un _array_ de grupos para la autenticación automática.
| vnd.bbva.group-id
| No
| String

| JWT_PUBLIC_KEY_ENDPOINT
| URL donde encontrar la clave pública para verificar el JWT.
| https://public-key-endpoint/key
| No (obligatorio si se usa JWT)
| String

| JWT_INSECURE_REQUEST_PKEY
| Indicador para determinar si se debe verificar la conexión TLS al obtener la clave pública en `JWT_PUBLIC_KEY_ENDPOINT`.
| _false_
| No
| String

| JWT_HEADER_NAME
| Cabecera HTTP donde encontrar el _token_ JWT si la autenticación es mediante JWT.
| X-USER-TOKEN
| No
| String

| JWT_USERNAME_CLAIM
| Nombre del _claim_ en el _token_ JWT que contiene el nombre de usuario.
| sub
| No
| String

| JWT_GROUPS_CLAIM
| Nombre del _claim_ en el _token_ JWT que contiene los grupos de usuarios.
| `groups`
| No
| String

| DISCOVERY_INSTANCE_NAME
| El nombre que se utiliza en Vault para almacenar los secretos de esta instancia. En _clusters_ _multi-tenant_ estará compuesto por el ID del _tenant_ y el nombre del servicio, por ejemplo, _tenant1-discovery_.
| discovery
| Sí
| String

| AUTHENTICATOR
| Elige un xref:operations-guide:end-user-authentication.adoc[método de autenticación]. Reemplaza `USE_JWT_AUTHENTICATION` y `USE_GOSEC_SSO_AUTH`, ya que no existen. El único valor para el que el despliegue está conectado de principio a fin es `gosec-sso`, que también es el valor predeterminado.
| gosec-sso
| Sí
| String

| SSO_URI
| URI para iniciar sesión mediante el SSO de _Stratio Gosec_. La autenticación la gestiona el `oauth2proxy` de _Stratio KEOS_, así que la instancia ya no necesita esta dirección. En desuso desde la versión 0.56.4-0.2.x.
| Por ejemplo: `+https://bootstrap.labs.stratio.com:9005/sso+`.
| No
| String

| JWT_COOKIE_NAME
| Nombre de la _cookie_ que emite el `oauth2proxy` de _Stratio KEOS_ y que transporta el _token_ JWT con la información del usuario. Se llamaba `OAUTH2_COOKIE_NAME` hasta la 0.50.21-0.2.x; se renombró en la 0.56.4-0.1.0.
| stratio-cookie
| No
| String

| VIRTUALIZER_JDBC_FROM_EXTRA_JARS
| Indica si se debe usar el _driver_ JDBC de _Stratio {modulename}_ aportado en `EXTRA_JARS` en lugar del incluido en la imagen.
| false
| No
| Boolean

| SERVICE_URL
| La URL de acceso a tu instancia de _Stratio Discovery_. Se compone automáticamente como `+https://${haproxyhost}${haproxypath}+` a partir de las opciones _URI host…_ y _URL path to access your Discovery service_ de la sección 'General' → 'Networking'.
| Por ejemplo: `+https://public01.labs.stratio.com/discovery+`.
| Sí
| String
|===

*Environment*

|===
| Propiedad | Descripción | Posible/por defecto | Obligatorio | Tipo

| MB_DB_TYPE
| El tipo de base de datos utilizada como repositorio de metadatos.
| postgres
| Sí
| String

| MB_DB_URL
| Si se define esta variable, se utilizará para establecer la conexión con la base de datos utilizada para almacenar los metadatos de la instancia. Si no está definido, en su lugar se usarán `MB_DB_HOST` y `MB_DB_PORT`.
| poolpostgrestls.s000001-datastores:5432
| Sí
| String

| MB_DB_DBNAME
| Nombre de la base de datos utilizada para guardar los metadatos de _Stratio Discovery_.
| discovery
| Sí
| String

| MB_DB_USER
| Nombre de usuario utilizado para conectarse a la base de datos en la que se guardan los metadatos de _Stratio Discovery_.
| postgres
| No
| String

| MB_DB_SSL
| Conexión segura TLS con la base de datos.
| _true_
| Sí
| Boolean

| MB_DB_PASS
| Contraseña para conectarse a la base de datos si se utiliza el usuario y la contraseña como mecanismo de autenticación. Solo si no se ha habilitado `MB_DB_SSL`.
| _password_
| No
| String

| MB_JDBC_PARAMETERS
| Una variable opcional para agregar a la cadena de conexión parámetros de configuración de JDBC adicionales.
| prepareThreshold=0
| No
| String

| PROXY_READ_TIMEOUT
| Tiempo de espera de lectura del proxy, en segundos, aplicable tanto al proxy interno como al externo.
| 300
| Sí
| Number

| DISCOVERY_CICD_API_IMPORT_TIMEOUT
| Tiempo de espera de Akka, en segundos, para las solicitudes al servicio de importación.
| 300s
| No
| String

| DISCOVERY_CICD_API_EXPORT_TIMEOUT
| Tiempo de espera de Akka, en segundos, para las solicitudes al servicio de exportación.
| 60s
| No
| String

| DISCOVERY_CICD_API_METABASE_TIMEOUT
| Tiempo de espera de la API de Metabase para solicitudes internas.
| 20s
| No
| String

| DISCOVERY_CICD_JAVA_OPTIONS
| Te permite configurar opciones de Java personalizadas cuando ejecutas el servicio de CI/CD.
| Ejemplo: `-Dakka.http.server.request-timeout=120s`.
| No
| String

| DISCOVERY_CICD_JAVA_INITIAL_RAM_PERCENTAGE
| Porcentaje de memoria inicial de Java en relación con la memoria total asignada a la instancia.
| -XX:InitialRAMPercentage=10.0
| No
| String

| DISCOVERY_CICD_JAVA_MAX_RAM_PERCENTAGE
| Porcentaje de memoria máxima de Java en relación con la memoria total asignada a la instancia.
| -XX:MaxRAMPercentage=25.0
| No
| String

| EXTRA_JARS
| Lista de ficheros JAR externos que se descargan en el directorio de _plugins_ de Metabase al arranque. Corresponde a la opción _Extra JARs to add to Metabase plugins folder_.
| Vacío
| No
| String

| CURL_CUSTOM_SECURITY_OPTS
| Opciones que se pasan a `curl` para descargar los ficheros de `EXTRA_JARS`. Se llamaba `WGET_CUSTOM_SECURITY_OPTS` hasta la versión 0.56.4-0.1.0, cuando la descarga pasó de `wget` a `curl`.
| Vacío. Si no se define, la imagen usa los certificados de la instancia, a partir de las variables que inyecta la plataforma.
| No
| String
|===
