= Variables de entorno

Aquí puedes consultar todas las posibles propiedades de _Stratio Discovery_ para desplegar una instancia:

* *Propiedad*: nombre del campo.
* *Descripción*: descripción del valor y su uso.
* *Posible/por defecto*: valores posibles y valores predeterminados.
* *Obligatorio*: _true_ o _false_.
* *Tipo*: tipo de valor.

|===
| Propiedad | Descripción | Posible/por defecto | Obligatorio | Tipo

| SERVICE_ID
| El nombre de la instancia (predeterminado = /discovery).
| discovery
| Si
| String

| KUBERNETES_NAMESPACE
| El nombre del _namespace_ donde está ubicada la instancia.
| s000001-apps
| Si
| String

| DEPLOYMENT_ENVIRONMENT
| Entorno de despliegue.
| keos
| No
| String

| TENANT
| _Tenant_ donde está desplegada la instancia.
| `${tenantId}`
| No
| String

| CPU_RESOURCE_TYPE
| Tipo de recurso de CPU a utilizar en cuanto al tipo de asignación en Kubernetes: +
- _Guaranteed_: recurso garantizado (solicitud = límite). +
- _Hard_: límite establecido, pero la solicitud puede ser menor. +
- _Soft_: sin límite, solo se establece la solicitud.
| _Guaranteed_
| Si
| String

| CPUs
| Número de CPU solicitados a cada instancia de _Stratio Discovery_.
| 2
| Si
| Number

| CPU_LIMIT
| En caso de que `CPU_RESOURCE_TYPE` sea _Hard_, este valor establece el límite de CPU para cada instancia de _Stratio Discovery_.
|
|
| Number

| INSTANCES
| Número de instancias de _Stratio Discovery_ para ejecutar.
| 1
| Si
| Number

| MEM_RESOURCE_TYPE
| Tipo de memoria a utilizar en cuanto a tipo de asignación en Kubernetes: +
- _Guaranteed_: recurso garantizado (solicitud = límite). +
- _Hard_: límite establecido, pero la solicitud puede ser menor. +
- _Soft_: sin límite, solo se establece la solicitud.
| _Guaranteed_
| Si
| String

| MEM
| Memoria (MB) para asignar a cada instancia de _Bootstrap_.
| 4096
| Si
| Number

| MEMORY_LIMIT
| En caso de que `MEM_RESOURCE_TYPE` sea _Hard_, este valor establece el límite de CPU para cada instancia de _Stratio Discovery_.
|
|
| Number

| JAVA_INITIAL_RAM_PERCENTAGE
| Porcentaje de memoria inicial de Java en relación con la memoria total asignada a la instancia.
| `-XX:InitialRAMPercentage=30.0`
| No
| String

| JAVA_MAX_RAM_PERCENTAGE
| Porcentaje de memoria máxima de Java en relación con la memoria total asignada a la instancia.
| `-XX:MaxRAMPercentage=70.0`
| No
| String

| force_pull_image
| Fuerza la descarga de la imagen de Docker cada vez que se crea una instancia.
| _true_
| Si
| Boolean
|===

*Seguridad*

|===
| Propiedad | Descripción | Posible/por defecto | Obligatorio | Tipo | Obsoleto

| VAULT_ENABLE
| Habilita la integración con Vault para recuperar secretos.
| true
| No
| Boolean
|

| VAULT_HOST
| _Host_ de conexión de Vault.
| vault.keos-core
| No
| String
|

| VAULT_PORT
| Puerto de conexión de Vault.
| 8200
| Si
| Number
|

| VAULT_ROLE
| Rol utilizado para recuperar un _token_ de Vault con una política predefinida. NOTA: solo se usa con la autenticación dinámica habilitada.
| `${Application.domain}-${Application.name}`
| No
| String
|

| USE_DYNAMIC_AUTHENTICATION
| Habilita la autenticación dinámica.
| true
| No
| String
|

| MB_USER_HEADER
| Cabecera HTTP con el usuario para el inicio de sesión utilizado para realizar una autenticación automática.
| vnd.bbva.user-id
| No
| String
|

| MB_GROUP_HEADER
| Cabecera HTTP con un _array_ de grupos para la autenticación automática.
| vnd.bbva.group-id
| No
| String
|

| JWT_PUBLIC_KEY_ENDPOINT
| URL donde encontrar la clave pública para verificar el JWT.
| https://public-key-endpoint/key
| No (obligatorio si se usa JWT)
| String
|

| JWT_INSECURE_REQUEST_PKEY
| Indicador para establecer si verificar la conexión TLS mientras se obtiene la clave pública en `JWT_PUBLIC_KEY_ENDPOINT`.
| _false_
| No
| String
|

| JWT_HEADER_NAME
| Cabecera HTTP donde encontrar el _token_ JWT si está seleccionada la autenticación a través de JWT.
| X-USER-TOKEN
| No
| String
|

| JWT_USERNAME_CLAIM
| Nombre del _claim_ en el _token_ JWT donde se proporciona el nombre de usuario.
| sub
| No
| String
|

| JWT_GROUPS_CLAIM
| Nombre del _claim_ en el _token_ JWT donde se proporcionan los grupos de usuarios.
| grupos
| No
| String
|

| DISCOVERY_INSTANCE_NAME
| El nombre utilizado en Vault para almacenar los secretos de esta instancia. En _clusters_ _multi-tenant_ estará compuesto por el ID del _tenant_ y el nombre del servicio, por ejemplo, _tenant1-discovery_.
| discovery
| Si
| String
|

| AUTHENTICATOR
| Elige un xref:operations-guide:end-user-authentication.adoc[método de autenticación]. Reemplaza `USE_JWT_AUTHENTICATION` y `USE_GOSEC_SSO_AUTH`.
| gosec-sso
| Si
| String
|

| SSO_URI
| URI para instaurar una sesión a través de SSO de _Stratio Gosec_. Esta variable es obligatoria solo si `USE_GOSEC_SSO_AUTH` se establece en `true`.
| Por ejemplo: `+https://bootstrap.labs.stratio.com:9005/sso+`.
| No
| String
|

| SERVICE_URL
| La URL de acceso de tu instancia de _Stratio Discovery_. Por lo general, esto se establece automáticamente en `+https://${haproxyhost}${haproxypath}+`, donde `haproxyhost` corresponde a `HAPROXY_1_VHOST` y `haproxypath` a `HAPROXY_1_PATH`.
| Por ejemplo: `+https://public01.labs.stratio.com/discovery+`.
| Si
| String
|
|===

*Environment*

|===
| Propiedad | Descripción | Posible/por defecto | Obligatorio | Tipo | Obsoleto

| MB_DB_TYPE
| El tipo de base de datos utilizada como repositorio de metadatos.
| postgres
| Si
| String
|

| MB_DB_URL
| Si se define esta variable, se utilizará para establecer la conexión con la base de datos utilizada para almacenar los metadatos de la instancia. Si no está definido, en su lugar se usarán `MB_DB_HOST` y `MB_DB_PORT`.
| poolpostgrestls.s000001-datastores:5432
| Si
| String
|

| MB_DB_DBNAME
| Nombre de la base de datos utilizada para guardar los metadatos de _Stratio Discovery_.
| discovery
| Si
| String
|

| MB_DB_USER
| Nombre de usuario utilizado para conectarse a la base de datos en la que se guardan los metadatos de _Stratio Discovery_.
| postgres
| No
| String
|

| MB_DB_SSL
| Conexión segura TLS con la base de datos.
| _true_
| Si
| Boolean
|

| MB_DB_PASS
| Contraseña para conectarse a la base de datos si se utiliza usuario y contraseña como mecanismo de autenticación. Solo en caso de que no se haya habilitado `MB_DB_SSL`.
| _password_
| No
| String
|

| MB_JDBC_PARAMETERS
| Una variable opcional para agregar a la cadena de conexión parámetros de configuración de JDBC adicionales.
| prepareThreshold=0
| No
| String
|

| PROXY_READ_TIMEOUT
| Tiempo de espera de lectura de proxy en segundos aplicado tanto al proxy interno como al externo.
| 300
| Si
| Número
|

| DISCOVERY_CICD_API_IMPORT_TIMEOUT
| Tiempo de espera de Akka en segundos para solicitudes al servicio de importación.
| 300s
| No
| String
|

| DISCOVERY_CICD_API_EXPORT_TIMEOUT
| Tiempo de espera de Akka en segundos para solicitudes al servicio de exportación.
| 60s
| No
| String
|

| DISCOVERY_CICD_API_METABASE_TIMEOUT
| Tiempo de espera de la API de Metabase para solicitudes internas.
| 20s
| No
| String
|

| DISCOVERY_CICD_JAVA_OPTIONS
| Te permite configurar opciones Java personalizadas cuando ejecuta el servicio de CICD.
| Ejemplo: `-Dakka.http.server.request-timeout=120s`.
| _false_
| String
|

| DISCOVERY_CICD_JAVA_INITIAL_RAM_PERCENTAGE
| Porcentaje de memoria inicial de Java en relación con la memoria total asignada a la instancia.
| -XX:InitialRAMPercentage=10.0
| No
| String
|

| DISCOVERY_CICD_JAVA_MAX_RAM_PERCENTAGE
| Porcentaje de memoria máxima de Java en relación con la memoria total asignada a la instancia.
| -XX:MaxRAMPercentage=25.0
| No
| String
|
