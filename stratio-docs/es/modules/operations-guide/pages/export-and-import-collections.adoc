= Importar y exportar colecciones

_Stratio Discovery_ te permite exportar colecciones junto con todos sus tableros, preguntas y subcolecciones en formato JSON, que luego se pueden importar en otra instancia de _Stratio Discovery_ siempre que ambas tengan la misma versión. Esta función será útil para mover colecciones entre entornos y puede integrarse de forma sencilla dentro de una herramienta de CI/CD.

_Stratio Discovery_ expone una API REST HTTP de Akka basada en _endpoints_ de exportación e importación:

== Exportar colección

Si deseas exportar una colección de _Stratio Discovery_, solo necesitas encontrar el identificador de la colección a exportar:

image::identify_colection_id.png[]

Luego, simplemente llama al _endpoint_ de exportación indicando el identificador de la colección. Esta solicitud debe autenticarse utilizando el identificador de sesión de _Stratio Discovery_ a través de la cabecera denominada `x-metabase-session`.

:tip-caption: CONSEJO

TIP: Para obtener más información sobre esta autorización, consulta la https://github.com/metabase/metabase/wiki/Using-the-REST-API[wiki de Metabase].

|===
| Tipo de solicitud | _Endpoint_ | Encabezados

| GET
| `/discovery-cicd/export/'collection_id'`
| `x-metabase-session: 'sessionId'` , `Content-Type: application/json`
|===

== Importar colección

Una vez que hayas exportado la colección, solo tienes que llamar al _endpoint_ de importación en el _Stratio Discovery_ de destino indicando, como datos sin procesar, el archivo en formato JSON que contiene la colección exportada. Para la autenticación, debes añadir a esta solicitud el identificador de sesión de _Stratio Discovery_ a través de la cabecera denominada `x-metabase-session`.

:tip-caption: CONSEJO

TIP: Para obtener más información sobre esta autorización, consulta la https://github.com/metabase/metabase/wiki/Using-the-REST-API[wiki de Metabase].

|===
| Tipo de solicitud | _Endpoint_ | Encabezados

| POST
| `/discovery-cicd/import?parentId='parent_collection'`
| `x-metabase-session: 'sessionId'`, `Content-Type: application/json`
|===

Como puedes ver, en este _endpoint_ puedes indicar opcionalmente la colección principal que deseas que herede la colección importada, a través del parámetro de consulta `parentId`.

:important-caption: IMPORTANTE

[IMPORTANT]
====
No puedes exportar:

* Cualquier colección personal.
* Una colección no creada previamente.
* Colecciones que contienen paneles que usan preguntas que no pertenecen a la colección exportada o una de sus subcolecciones.
* Colecciones que contienen dos o más preguntas/tableros/subcolecciones con el mismo nombre.

No puedes importar:

* Una colección en un _Stratio Discovery_ de destino que no tiene los mismos nombres de base de datos, campos y tablas que contienen las preguntas exportadas.

En estos casos, cada _endpoint_ responderá con su correspondiente error.
====

Deshabilitar la opción de configuración `FRIENDLY TABLE AND FIELD NAMES` acelerará el proceso de exportación/importación. Esta opción se encuentra en la sección general de la configuración de Metabase:

image::humanize_fields.png[]

Esta opción de configuración debe estar deshabilitada tanto en la instancia de _Stratio Discovery_ de origen como en la de destino, si deseas aprovecharla.
