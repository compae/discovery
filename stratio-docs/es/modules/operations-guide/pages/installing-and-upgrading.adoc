= Instalación y actualización

WARNING: Se recomienda encarecidamente instalar _Stratio Discovery_ a través de _Stratio Command Center_, ya que este último se encarga de generar los secretos necesarios, registrar el servicio y completar automáticamente las variables de todo el entorno en el momento del despliegue.

Consulta las siguientes guías detalladas para iniciar el proceso:

* xref:operations-guide:installing-and-upgrading/prerequisites.adoc[Prerrequisitos]
* xref:operations-guide:installing-and-upgrading/deployment.adoc[Despliegue]
* xref:operations-guide:installing-and-upgrading/verify-installation.adoc[Verificar instalación]
* xref:operations-guide:installing-and-upgrading/upgrade.adoc[Actualización de versión]

Para solucionar posibles problemas, puedes consultar la xref:operations-guide:installing-and-upgrading/environment-variables.adoc[lista de variables de entorno de la instancia]: ten en cuenta que la mayoría de ellas son independientes del entorno de despliegue utilizado.
