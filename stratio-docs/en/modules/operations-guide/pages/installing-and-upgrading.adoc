= Installation and upgrades

WARNING: We strongly recommend installing _Stratio Discovery_ using _Stratio Command Center_ because it takes care of generating the required secrets, registering the service and automatically populating the variables for the entire environment during deployment.

Please refer to the following step-by-step guides to start the process:

* xref:operations-guide:installing-and-upgrading/prerequisites.adoc[Prerequisites]
* xref:operations-guide:installing-and-upgrading/deployment.adoc[Deployment]
* xref:operations-guide:installing-and-upgrading/verify-installation.adoc[Verify installation]
* xref:operations-guide:installing-and-upgrading/upgrade.adoc[Version upgrade]

For troubleshooting, refer to the xref:operations-guide:installing-and-upgrading/environment-variables.adoc[list of environment variables of the instance]: note that most of them are independent of the deployment environment used.
