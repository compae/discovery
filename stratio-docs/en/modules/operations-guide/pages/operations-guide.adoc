= Operations guide

This section gives you all of the information on how to configure, install and operate a _Stratio Discovery_ instance.

Regardless of why you're viewing this section, you should read this xref:operations-guide:key-concepts.adoc[short introduction to _Stratio Discovery_] first. Knowing the architecture will not only help you to troubleshoot problems, but also to make adjustments in the deployment.

Then, visit xref:operations-guide:installing-and-upgrading.adoc[this page and its sections] to successfully perform a complete installation.
