= Upgrade planning

This page is a decision index, not a procedure. Use it to select the sheet for your upgrade route and plan the maintenance window. When the intervention day arrives, see the xref:operations-guide:installing-and-upgrading/upgrade.adoc[upgrade procedure] to execute it step by step.

Each upgrade route has its own sheet, which indicates how long the service is unavailable, what stops working, the upgrade order relative to other modules, and whether you can roll back. These sheets are for those who plan and execute the upgrade in each environment: they collect decisions, durations, and impacts, and refer to the procedure that describes each step.

TIP: Start with the xref:operations-guide:installing-and-upgrading/upgrade-overview/from-0-50-21-to-0-56-4.adoc#summary[sheet summary]. It answers, at a glance, everything you need to decide the maintenance window.

== How to read a sheet

Each sheet follows the same structure, so that the impact of each upgrade is described in the same terms:

* *The answers are brief.* Each row indicates a yes, a no, or a figure, and the last column refers to the section or page that develops it in full.
* *No field is left empty.* When something does not apply, the sheet indicates it and explains why, instead of letting you discover it in the environment.
* *The detail is kept in the procedure pages.* The sheet links to them instead of reproducing them and marks any unmeasured duration as estimated.
