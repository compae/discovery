= Environment variables

Here you can consult all the possible properties of _Stratio Discovery_ for deploying an instance:

* *Property*: name of the field.
* *Description*: description of the value and its use.
* *Possible/default*: possible values and default values.
* *Mandatory*: Yes or No.
* *Type*: type of value.

|===
| Property | Description | Possible/default | Mandatory | Type

| SERVICE_ID
| The name of the instance (default = /discovery).
| discovery
| Yes
| String

| KUBERNETES_NAMESPACE
| The name of the namespace where the instance is located.
| s000001-apps
| Yes
| String

| DEPLOYMENT_ENVIRONMENT
| Deployment environment.
| keos
| No
| String

| TENANT
| Tenant where the instance is deployed.
| `${tenantId}`
| No
| String

| CPU_RESOURCE_TYPE
| Type of CPU resource to use in terms of the type of allocation in Kubernetes: +
- _Guaranteed_: guaranteed resource (request = limit). +
- _Hard_: limit set, but the request can be lower. +
- _Soft_: no limit; only the request is set.
| _Guaranteed_
| Yes
| String

| CPUs
| Number of CPUs requested per instance of _Stratio Discovery_.
| 2
| Yes
| Number

| CPU_LIMIT
| In case `CPU_RESOURCE_TYPE` is _Hard_, this value sets the CPU limit for each instance of _Stratio Discovery_.
|
|
| Number

| INSTANCES
| Number of _Stratio Discovery_ instances to run.
| 1
| Yes
| Number

| MEM_RESOURCE_TYPE
| Type of memory to use in terms of the type of allocation in Kubernetes: +
- _Guaranteed_: guaranteed resource (request = limit). +
- _Hard_: limit set, but the request can be lower. +
- _Soft_: no limit, only the request is set.
| _Guaranteed_
| Yes
| String

| MEM
| Memory (MB) allocated to each instance of _Stratio Discovery_.
| 4096
| Yes
| Number

| MEMORY_LIMIT
| In case `MEM_RESOURCE_TYPE` is _Hard_, this value sets the memory limit for each instance of _Stratio Discovery_.
|
|
| Number

| JAVA_INITIAL_RAM_PERCENTAGE
| Percentage of Java's initial memory in relation to the total memory allocated to the instance.
| `-XX:InitialRAMPercentage=30.0`
| No
| String

| JAVA_MAX_RAM_PERCENTAGE
| Percentage of Java's maximum memory in relation to the total memory allocated to the instance.
| `-XX:MaxRAMPercentage=70.0`
| No
| String

| force_pull_image
| Forces the Docker image to be downloaded each time an instance is created.
| _true_
| Yes
| Boolean
|===

*Security*

|===
| Property | Description | Possible/default | Mandatory | Type

| VAULT_ENABLE
| Enables Vault integration to retrieve secrets.
| true
| No
| Boolean

| VAULT_HOST
| Vault connection host.
| vault.keos-core
| No
| String

| VAULT_PORT
| Vault connection port.
| 8200
| Yes
| Number

| VAULT_ROLE
| Role used to retrieve a Vault token through a predefined policy. NOTE: only used with dynamic authentication enabled.
| `${Application.domain}-${Application.name}`
| No
| String

| USE_DYNAMIC_AUTHENTICATION
| Enables dynamic authentication. Deprecated since version 0.56.4-0.2.x.
| true
| No
| String

| MB_USER_HEADER
| HTTP header with the username used for automatic authentication.
| vnd.bbva.user-id
| No
| String

| MB_GROUP_HEADER
| HTTP header with an array of groups for automatic authentication.
| vnd.bbva.group-id
| No
| String

| JWT_PUBLIC_KEY_ENDPOINT
| URL where to find the public key to verify the JWT.
| https://public-key-endpoint/key
| No (mandatory if JWT is used)
| String

| JWT_INSECURE_REQUEST_PKEY
| Indicator to determine whether the TLS connection should be verified when obtaining the public key at `JWT_PUBLIC_KEY_ENDPOINT`.
| _false_
| No
| String

| JWT_HEADER_NAME
| HTTP header where to find the JWT token if authentication is through JWT.
| X-USER-TOKEN
| No
| String

| JWT_USERNAME_CLAIM
| Name of the claim in the JWT token that contains the username.
| sub
| No
| String

| JWT_GROUPS_CLAIM
| Name of the claim in the JWT token that contains the user groups.
| `groups`
| No
| String

| DISCOVERY_INSTANCE_NAME
| The name used in Vault to store the secrets of this instance. On multi-tenant clusters, it is composed of the tenant ID and the service name; for example, _tenant1-discovery_.
| discovery
| Yes
| String

| AUTHENTICATOR
| Choose an xref:operations-guide:end-user-authentication.adoc[authentication method]. Replaces `USE_JWT_AUTHENTICATION` and `USE_GOSEC_SSO_AUTH`, since they no longer exist. The only value wired end-to-end is `gosec-sso`, which is also the default.
| gosec-sso
| Yes
| String

| SSO_URI
| URI to log in through the _Stratio Gosec_ SSO. Authentication is managed by the _Stratio KEOS_ `oauth2proxy`, so the instance no longer needs this address. Deprecated since version 0.56.4-0.2.x.
| For example: `+https://bootstrap.labs.stratio.com:9005/sso+`.
| No
| String

| JWT_COOKIE_NAME
| Name of the cookie that the _Stratio KEOS_ `oauth2proxy` issues and that carries the JWT token with the user information. It was called `OAUTH2_COOKIE_NAME` until 0.50.21-0.2.x; it was renamed in 0.56.4-0.1.0.
| stratio-cookie
| No
| String

| VIRTUALIZER_JDBC_FROM_EXTRA_JARS
| Indicates whether to use the _Stratio {modulename}_ JDBC driver provided in `EXTRA_JARS` instead of the one included in the image.
| false
| No
| Boolean

| SERVICE_URL
| The access URL to your _Stratio Discovery_ instance. It is automatically composed as `+https://${haproxyhost}${haproxypath}+` from the _URI host…_ and _URL path to access your Discovery service_ options of the 'General' → 'Networking' section.
| For example: `+https://public01.labs.stratio.com/discovery+`.
| Yes
| String
|===

*Environment*

|===
| Property | Description | Possible/default | Mandatory | Type

| MB_DB_TYPE
| The type of database used as the metadata repository.
| postgres
| Yes
| String

| MB_DB_URL
| If this variable is defined, it will be used to establish the connection with the database used to store the instance's metadata. If not defined, `MB_DB_HOST` and `MB_DB_PORT` will be used instead.
| poolpostgrestls.s000001-datastores:5432
| Yes
| String

| MB_DB_DBNAME
| Name of the database used to save the _Stratio Discovery_ metadata.
| discovery
| Yes
| String

| MB_DB_USER
| Username used to connect to the database in which the _Stratio Discovery_ metadata is saved.
| postgres
| No
| String

| MB_DB_SSL
| Secure TLS connection with the database.
| _true_
| Yes
| Boolean

| MB_DB_PASS
| Password to connect to the database if you use a user and password as the authentication mechanism. Only if `MB_DB_SSL` has not been enabled.
| _password_
| No
| String

| MB_JDBC_PARAMETERS
| An optional variable to add additional JDBC configuration parameters to the connection string.
| prepareThreshold=0
| No
| String

| PROXY_READ_TIMEOUT
| Read timeout of the proxy, in seconds, applicable to both the internal and the external proxy.
| 300
| Yes
| Number

| DISCOVERY_CICD_API_IMPORT_TIMEOUT
| Akka timeout, in seconds, for requests to the import service.
| 300s
| No
| String

| DISCOVERY_CICD_API_EXPORT_TIMEOUT
| Akka timeout, in seconds, for requests to the export service.
| 60s
| No
| String

| DISCOVERY_CICD_API_METABASE_TIMEOUT
| Metabase API timeout for internal requests.
| 20s
| No
| String

| DISCOVERY_CICD_JAVA_OPTIONS
| Allows you to configure custom Java options when you run the CI/CD service.
| Example: `-Dakka.http.server.request-timeout=120s`.
| No
| String

| DISCOVERY_CICD_JAVA_INITIAL_RAM_PERCENTAGE
| Percentage of Java's initial memory in relation to the total memory allocated to the instance.
| -XX:InitialRAMPercentage=10.0
| No
| String

| DISCOVERY_CICD_JAVA_MAX_RAM_PERCENTAGE
| Percentage of Java's maximum memory in relation to the total memory allocated to the instance.
| -XX:MaxRAMPercentage=25.0
| No
| String

| EXTRA_JARS
| List of external JAR files that are downloaded to the Metabase plugins directory at startup. Corresponds to the _Extra JARs to add to Metabase plugins folder_ option.
| Empty
| No
| String

| CURL_CUSTOM_SECURITY_OPTS
| Options passed to `curl` to download the files in `EXTRA_JARS`. It was called `WGET_CUSTOM_SECURITY_OPTS` until version 0.56.4-0.1.0, when the download moved from `wget` to `curl`.
| Empty. If not defined, the image uses the instance's certificates, based on the variables injected by the platform.
| No
| String
|===
