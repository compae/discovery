= Environment variables

This section covers all of the possible properties of _Stratio Discovery_ to deploy an instance:

* *Property*: field name.
* *Description*: description of the value and its use.
* *Possible/default*: possible values and default values.
* *Required*: _true_ or _false_.
* *Type*: type of value.

|===
| Property | Description | Possible/default | Required | Type:

| cpus
| CPU quotas to assign to each _Stratio Discovery_ instance.
|
|
|

| instances
| Number of _Stratio Discovery_ instances to run.
|
|
|

| id
| The name of the instance (default = /discovery).
|
|
|

| mem
| Memory (MB) to allocate to each _Bootstrap_ instance.
| 2048
| Yes
| Number

| force_pull_image
| Forces the Docker image to be downloaded each time an instance is created.
| _true_
| Yes
| Boolean
|===

*Security*:

| Indicator to set whether to verify the TLS connection while obtaining the public key in `JWT_PUBLIC_KEY_ENDPOINT`.

| HTTP header where to find the JWT token if authentication with JWT is selected.

| String
|
