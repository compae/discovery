= Verify the installation

Follow these steps to verify that the installation or upgrade of _Stratio Discovery_ has been performed correctly:

. Check in _Stratio Command Center_ that the service reports the expected version and that its state is healthy. During startup, the `/api/health` endpoint responds with code "503" and the body `{"status":"initializing"}`; when it finishes, it responds with code "200".
. Access the user interface and log in. If the _Use group whitelist_ option is disabled (the default), any user that _Stratio Gosec_ SSO authenticates can access it; if you enable it, use a user from the groups in the _Allowed groups_ option.
. Check that a user from the group configured in the _Admin group_ option has administration permissions, which confirms that group synchronization with _Stratio Gosec_ works.
. Go to 'New question' and run a query on the _Stratio {modulename}_ database.
. Repeat the question on a _Stratio PostgreSQL Operator_ database, if you have one connected.
. Launch catalog synchronization on one of those databases and confirm it finishes without errors.

TIP: After an upgrade, also check that existing collections, questions, and dashboards open and execute, and that dashboard subscriptions keep their names.
