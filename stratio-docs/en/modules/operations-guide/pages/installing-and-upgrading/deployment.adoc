= Installation

== Configuration

It is possible to deploy _Stratio Discovery_ through _Stratio Command Center_ by clicking on *'Services' → 'Deploy service'* (blue button).

image::cct_services_list_discovery_deployment_0001.png[]

At this point, the entire service catalog will be displayed. Here, you must filter by the version you want to deploy and search for "Discovery" in the search box.

image::cct_deploy_service_discovery_deployment_0002.png[]

Once you have configured everything, select the "Discovery" service, and you will be redirected to a confirmation page where you can choose a minor version of the service, if needed. Once you have decided which version to deploy, click on "Deploy" to confirm.

image::cct_confirm_version_discovery_deployment_0003.png[]

The following screen shows the basic configuration requirements ('Pre-deployment').

The _Stratio Command Center_ provides a list of services installed in the cluster so you can configure it correctly.

image::cct_predeploy_discovery_deployment_0004.png[]

=== Namespace where the service will be deployed

Depending on your login, you may need to select the namespace where you want to deploy your service. In the following example, it is set to `s000001,` and the namespace name is set from the tenant to `s000001-discovery`:

image::cct_select_tenant_namespace_discovery_deployment_0005.png[]

=== Application metadata store

_Stratio Command Center_ allows you to choose the _Stratio PostgreSQL_ available in the cluster to connect to. There are two service discovery selectors: the first is used to build the URL and can be PostgreSQL® or PgBouncer, and the second is used to create the policies and the database. Note that both fields must be consistent.

=== Defining placements for _Stratio Discovery_

At this point, _Stratio Command Center_ allows you to perform an advanced search for placements in which you can select the affinity rules for the _Stratio Discovery_ instance. These placements are entirely optional.

=== Priority for _Stratio Discovery_ (priority classes)

_Stratio Command Center_ provides you with a list of the priority classes configured in the cluster. You can choose the service's deployment priority.

WARNING: The application name must be unique within the tenant. Therefore, you cannot deploy two instances with the same name in different namespaces if they belong to the same tenant. However, you can deploy two instances with the same name in different tenants.

Once you confirm the configuration on the 'Pre-deployment' screen, a form will open where you can complete it in more detail.

image::cct_configure_discovery_deployment_0005.png[]

If you need to set up an advanced configuration, click on "Customize deployment", right below the name and version of the service you are installing:

image::cct_advanced_configuration_discovery_deployment_0006.png[]

The deployment configuration is divided into different sections, which are shown in the menu on the left:

* *General*, where all the most essential settings are located.
* *Settings*, where you can configure the instance according to the user's needs.
* *Environment*, where all cluster's global environment variables are automatically configured (this is a read-only section).

Among the settings in the *General* section, you can set the name of the group with administrator permissions (`Admin group`) and the groups that contain users with limited permissions (`Allowed groups`) in _Stratio Discovery_.

image::users_discovery.png[]

Some of the most common advanced settings that can be customized are in 'Settings'. In this section, you can configure Java settings for exporting and importing service collections as well as other Akka HTTP and Nginx settings. Below, this section is shown with its default values.

image::cct_advanced_settings_discovery_deployment_0009.png[]

Since there are many variables to configure, the operator should look up the meaning of a variable (when the name isn't self-explanatory) by clicking the *Help* (?) icon, then searching for the desired property in the related section.

image::cct_help_discovery_deployment_0007.png[]

For example, if you want to know what the `Nginx` property is and what it does, just go to 'Help' -> 'Administration Panel' -> 'Settings', scroll down, and go to *Nginx* or use the search box to find the information about 'Nginx'.

image::cct_help_tooltip_discovery_deployment_0008.png[]

By default, _Stratio Discovery_ will be deployed integrated with the _Stratio GoSec_ SSO. This means the deployed instance will be registered in the _Stratio GoSec_ SSO as a service, and an additional secret will be registered in Vault, but don't worry about how to do this because _Stratio Command Center_ will do it on its own.

== Deployment

Now that everything is set up… click on "Deploy"!

image::cct_deploy_discovery_0010.png[]

Everything should work immediately, and the instance should start running soon.
