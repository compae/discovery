= Release notes

These are the highlights of _Stratio Discovery_ in the latest releases:

== 0.56.4-0.2.0 (July 22, 2026)

* Improved performance of the synchronization of _Stratio Virtualizer_ databases with numerous schemas and tables.
* Fixed synchronization errors on large _Stratio Virtualizer_ collections (the timeout for unreturned JDBC connections is now disabled by default).
* Update of the _Stratio Virtualizer_ JDBC driver to version 4.0.1.
* Fixed medium-severity vulnerabilities.
* *Breaking change*: the secrets move to the _Stratio KEOS_ Vault injector, so the platform must be on Universe 15.1 before upgrading, and the descriptor requests the _KEOS CA secret name_ and _KEOS CA name (key inside secret)_ fields.

== 0.56.4-0.1.3 (May 20, 2026)

* Fixed high- and critical-priority vulnerabilities.

== 0.56.4-0.1.2 (March 4, 2026)

* Update of the _Stratio Virtualizer_ JDBC driver to version 3.1.0.

== 0.56.4-0.1.1 (December 5, 2025)

* Update of the _Stratio Virtualizer_ JDBC driver to version 3.0.1.

== 0.56.4-0.1.0 (November 4, 2025)

* Metabase update: version 0.56.4 is now used. Certain features introduced in Metabase 0.51, such as actions, models created from CSV, timelines, and alerts, are still not compatible with exporting and importing _discovery-cicd_ collections.
* Update of the _Stratio Virtualizer_ JDBC driver to version 3.0.0.
* A deployment option has been added in _Stratio Command Center_: _Use virtualizer jdbc from Extra JARs_ (the `VIRTUALIZER_JDBC_FROM_EXTRA_JARS` environment variable) to not use the _Stratio Virtualizer_ JDBC driver included in the image, but obtain it from the _Extra JARs to add to Metabase plugins folder_ (the `EXTRA_JARS` environment variable).
* *Breaking change*: the _Skip Metabase's Statement final cancellation in Virtualizer driver_ deployment option in _Stratio Command Center_ has been removed (environment variable: `VIRTUALIZER_DRIVER_SKIP_STMT_CANCELLATION`). This option prevented JDBC connections from being blocked by _Stratio Virtualizer_ servers before version 0.11.0; therefore, you must now connect to servers running version 0.11.0 or higher.
* *Breaking change*: the image moves to Java 21 and changes its base, its process supervisor, and its web server; the Amazon Athena driver is removed; the audit of the content of the API responses disappears; and several environment variables are removed or renamed. See the full list in the xref:ROOT:what-is-new/breaking-changes.adoc#v0564-01x[breaking changes of 0.56.4-0.1.0].

== 0.50.21-0.2.0 (July 22, 2026)

Maintenance version of the 0.50.21 line, included in Universes 14.8, 14.9, and 14.10.

* Improved performance of the synchronization of _Stratio {modulename}_ databases with numerous schemas and tables.
* Update of the _Stratio {modulename}_ JDBC driver to version 2.32.3.

== 0.50.21-0.1.4 (June 30, 2026)

* The "portal "C_X" does not exist" error in the _Stratio PostgreSQL Operator_ driver has been fixed again.

== 0.50.21-0.1.3 (May 12, 2025)

* A deployment option has been added in _Stratio Command Center_: _Extra JARs to add to Metabase plugins folder_, to specify a list of URLs of JAR files to be added to the Metabase plugins folder. This lets you add new drivers or required dependencies, such as the Oracle JDBC required by the Metabase Oracle driver (environment variable: `EXTRA_JARS`).
* A deployment option has been added in _Stratio Command Center_, _Hex-encode user-provided parameters in SQL queries_, to configure the SQL injection prevention mechanism when interpolating parameters into the _Stratio Virtualizer_ SQL queries. Hex encoding is more secure, but may cause problems when the query is resolved natively, and the data store does not know how to decode the parameters (environment variable: `VIRTUALIZER_DRIVER_HEX_ENCODE_SQL_PARAMS`).
* Support for the use of questions as values in the filters of other questions when exporting and importing collections in _discovery-cicd_.
* An issue in the _Stratio Virtualizer_ driver that prevented the synchronization of schema and table names that contained hyphens has been fixed (through the update of the _Stratio Virtualizer_ JDBC to version 2.31.0).
* An issue in the _Stratio Virtualizer_ driver in which the correct SQL dialect was not being used for query formatting has been fixed.

== 0.50.21-0.1.2 (November 13, 2024)

* The _Stratio Virtualizer_ JDBC version has been downgraded to 2.27.0 to avoid an issue present in higher versions, in which a memory overflow occurred.

== 0.50.21-0.1.1 (November 7, 2024)

* A deployment option has been added in _Stratio Command Center_ to prevent the blocking of JDBC connections with _Stratio Virtualizer_ servers earlier than version 0.11.0. The new _Skip Metabase's Statement final cancellation in Virtualizer driver_ configuration allows disabling the automatic cancellation of JDBC statements that caused this problem (environment variable: `VIRTUALIZER_DRIVER_SKIP_STMT_CANCELLATION`).

== 0.50.21-0.1.0 (October 7, 2024)

* Metabase update: version 0.50.21 is now used, although certain features, such as actions, models created from CSV, timelines, and alerts, are not compatible with the export and import of _discovery-cicd_ collections.
* *Breaking change*: the integration with the _Stratio Gosec_ SSO has changed. Now, the Oauth2 flow is delegated to the _Stratio KEOS_ `oauth2proxy`, and the "discovery-oauth-cookie" cookie is no longer used. Instead, _stratio-cookie_ is set, which contains a JWT token with user information similar to that in the previous cookie, with the advantage that the rest of the Stratio applications recognize this new token. In addition, access to the Metabase API no longer requires this cookie; only the "metabase.SESSION" cookie is needed. Integrations with the _discovery-cicd_ API that simulated a login to retrieve the "discovery-oauth-cookie" cookie and then obtain the "metabase.SESSION" cookie must be adjusted to use the new _stratio-cookie_ instead.

== 0.43.4-0.3.0 (February 6, 2024)

* Fixed an issue in which the subject of the dashboard subscription emails showed a UUID instead of the dashboard name.

== 0.43.4-0.2.0 (July 21, 2023)

* Import and export of SQL code snippets in _discovery-cicd_.
* Proper handling of _questions_ that contain links to other _questions_ or _dashboards_ in _discovery-cicd_.
* Support for _placements_ and _priority classes_ in the deployment of _Stratio Discovery_.
* Use of percentages to configure the memory of the Java virtual machines associated with Metabase and _discovery-cicd_.
* Fix: greater ease in configuring _discovery-cicd_ timeouts and avoiding common errors.
* Vulnerability fix: update of the Prometheus Java agent to version 0.19.0 (vulnerability in the SnakeYAML package GHSA-mjmj-j48q-9wg2).
* Vulnerability fix: session cookies are no longer shown in the `DEBUG` level logs of the Metabase Jetty server.

== 0.43.4-0.1.4 (April 20, 2023)

* It is taken into account that cards can use other cards as input data in _discovery-cicd_.

== 0.43.4-0.1.3 (February 16, 2023)

* Fix: update of the Crossdata JDBC to version 2.24.0-7394c02 (to resolve the synchronization of Delta tables)
