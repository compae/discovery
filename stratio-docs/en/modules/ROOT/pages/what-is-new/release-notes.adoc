= Release notes

Here are the most relevant developments of _Stratio Discovery_ in the latest releases:

== 0.43.4-0.2.0 (September 2023)

* Import and export snippets of SQL code in _discovery-cicd_.
* Correct handling of questions that have links to other questions or dashboards in _discovery-cicd_.
* Support for placements and priority classes in _Stratio Discovery_ deployment.
* Use of percentages to configure the memory of Java virtual machines associated with Metabase and _discovery-cicd_.
* Fix: easier configuration of _discovery-cicd_ timeouts to avoid common errors.
* Vulnerability fix: Prometheus Java agent update to 0.19.0 (SnakeYAML package vulnerability GHSA-mjmj-j48q-9wg2).
* Vulnerability fix: session cookies are no longer displayed in the `DEBUG` level logs of the Metabase Jetty server.

== 0.43.4-0.1.4 (April 2023)

* Fix: solves a import problem with collection with questions using other saved questions.

== 0.43.4-0.1.3 (February 2023)

* Fix: bump Crossdata JDBC to 2.24.0-7394c02 (fix sync of Delta tables)

== 0.43.4-0.1.2 (December 2022) _Universe 13.0_

* Fix: Do not throw "fetchSize" error when doing graphical queries with a limit in the _Stratio Crossdata_ driver.

== 0.43.4-0.1.0 (September 2022)

* Upgrade to Metabase 0.43.4.
* Improvements in error management of the _discovery-cicd_ API.
* Import and export dashboard subscriptions to _discovery-cicd_ .
* Vulnerability fix: upgrading to version 0.17.1 of the Prometheus Java Agent.

== 0.42.2-0.1.1 (June 13, 2022) _Scorpio 11.1_

* Added missing sync scheduling options to our Metabase drivers.

== 0.42.2-0.1.0 (March 22, 2022)

* Upgrade to Metabase 0.42.
* Addition to the configuration to add all of the necessary SSL options with a simple click on the _stratiopostgres_ driver.
* Prometheus metrics fixed.

== 0.40.7-0.1.1 (February 2, 2022)

* Solution: names with _display$$_$$names_ not compared while filtering fields.
* Vulnerability fix: included nginx offers insecure TLS protocols.
* Vulnerability fix: authentication broken when using the _gosec-sso_ authenticator.

== 0.40.7-0.1.0 (December 14, 2021)

* _discovery-cicd_: conservation of _dashboard_ and _question_ IDs when importing.
* Upgrade to Metabase 0.40.7 (image from builder 0.40.7-0.1.0).
* Vulnerability fix: update to Java 11.
* Vulnerability fix: Prometheus Java Agent updated to 0.14.0.
* Vulnerability fix: metabase-builder updated to 0.40.7-0.1.0.
