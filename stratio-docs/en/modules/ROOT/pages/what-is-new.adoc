= What's new

Discover the main improvements in _Stratio Discovery_ 0.56.4-0.2.X, the Universe 15.1 version released on July 22, 2026. Since the upgrade is performed directly from Universe 14.10, this page also collects the new features incorporated in the 0.56.4-0.1.X line. Before upgrading, review the xref:ROOT:what-is-new/breaking-changes.adoc#v0564-02x[breaking changes], since they may affect compatibility. To plan the intervention, see the xref:operations-guide:installing-and-upgrading/upgrade-overview.adoc[upgrade planning].

TIP: See the full details by version in the xref:ROOT:what-is-new/release-notes.adoc[release notes].

== What's new in 0.56.4-0.2.X

* *Faster synchronization with _Stratio {modulename}_*: improves the performance of the synchronization of databases with numerous schemas and tables. It is also available in 0.50.21-0.2.0, the version of Universes 14.8, 14.9, and 14.10.
* *Update of the _Stratio {modulename}_ JDBC driver* to version 4.0.1.
* *End of synchronization errors on large _Stratio {modulename}_ collections*.
* *The secrets are obtained from the _Stratio KEOS_ Vault injector*, instead of being downloaded during startup.

== New features incorporated since 0.56.4-0.1.X

* *Metabase update to version 0.56.4*, from 0.50.21. See https://www.metabase.com/releases[Metabase release notes] for details on the new features across those six versions.
* *New _Use virtualizer jdbc from Extra JARs_ deployment option*: allows not using the _Stratio {modulename}_ JDBC driver included in the image and obtaining it from the _Extra JARs to add to Metabase plugins folder_ option.
* *New _Crossdata log level_ deployment option*: controls the log level of the _Stratio {modulename}_ JDBC driver, with "INFO" as the default value.
* *Renewed image*: the image moves to Java 21 and to a new base, process supervisor, and internal web server, which resolves the vulnerabilities that the previous one carried.
