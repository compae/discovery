= Quick start guide

_Stratio Discovery_ is a simple and powerful analysis tool that allows anyone to learn and make decisions from the data of their company. To access it, build the address in the browser with the two values you configured in _Stratio Command Center_, in the 'General' → 'Networking' section: the one of the "URI host…" option and the one of the "URL path to access your Discovery service" option.

For example:

* "URI host…" = `discovery.labs.stratio.com`
* "URL path to access your Discovery service" = `/discovery`

The final URL would be `\https://discovery.labs.stratio.com/discovery`.

== Asking new questions

Click "Ask a question" at the top of the screen. You'll now be in the question selection menu. Select "Custom" for a custom question.

Use the bar across the page to ask your questions. Now, you can select the desired table, *Test*:

image::select_a_table.png[]

Click on "Run" to display the table:

image::table_example.png[]

Let's start with a simple question: how many people have registered since 2010? To find out, you need to filter the data by the *field you are interested in*, in this case *start_date*.

After selecting the *start_date* from the filter drop-down, a list of options for the filter will be displayed. Choose "Previous" and type the number 10 in the text box. Then click "Add filter".

image::filtering.png[]

You'll then need to tell _Stratio Discovery_ what you want to view. Under the *View* drop-down menu, select "Count of rows".
