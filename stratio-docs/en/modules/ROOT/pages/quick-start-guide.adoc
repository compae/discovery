= Quick start guide

_Stratio Discovery_ is a simple, powerful analytics tool that lets anyone learn from and make decisions based on their company's data. To access, compose in the browser the address with the two values you configured in _Stratio Command Center_, in the 'General' → 'Networking' section: the one from the _URI host…_ option and the one from the _URL path to access your Discovery service_ option.

For example:

* _URI host…_ = `discovery.labs.stratio.com`
* _URL path to access your Discovery service_ = `/discovery`

The final URL would be `\https://discovery.labs.stratio.com/discovery`.

== Querying new questions

Click on "Ask a question" at the top of the screen. You are now in the question selection menu. Please select "Custom" for a custom query.

The bar you see on the page is the one you will use to ask your questions. Now, you can select the desired table, *Test*:

image::select_a_table.png[]

If you click on the "Run" button, the table will be shown:

image::table_example.png[]

Start with a simple question: how many people have registered since 2010? To find out, filter the data by *the field that interests you*, in this case *_fecha++_++comienzo_* (_start++_++date_).

After selecting "_fecha++_++comienzo_" in the filters dropdown, a list of filter options will be shown. Choose "Previous" and type the number 10 in the text box. Then, click on "Add filter".

image::filtering.png[]
